# 🚀 Single Store eCommerce  

This project is a minimal eCommerce store built with **React** for the frontend and a lightweight backend for managing addresses and payment status.  

## 📂 Project Structure  

- **Product Images:**  
  - Each product has its own folder named `productX` (e.g., `product1`, `product2`, etc.).  
  - Inside each folder, images are named as `pX-Y` (e.g., `p1-1`, `p1-2` for `product1`).  
  - The last digit (`Y`) increments for each additional image of the product.  

- **Localization:**  
  - All text content is stored in `locales/en.tsx`.  
  - Update this file to modify the UI text.  

- **Product List:**  
  - All products are listed in `productsList.tsx`.  
  - This file contains product details like name, price, and images.  

## 📌 Features  
✅ Static product display with images stored locally.  
✅ Cart stored in local storage.  
✅ Minimal backend to handle orders and payments.
